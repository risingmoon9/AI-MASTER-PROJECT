# IQL-Ref implementation specification

`hqa_orl/reference_iql.py` is an **official-equation PyTorch port** of the
[official Implicit Q-Learning implementation](https://github.com/ikostrikov/implicit_q_learning/tree/09d700248117881a75cb21f0adb95c6c8a694cb2),
pinned to commit `09d700248117881a75cb21f0adb95c6c8a694cb2`.
The source snapshot, MIT license, and hash manifest are in this directory.
The upstream JAX modules are retained for inspection and are not imported by
the project training code.

## Implemented correspondence

| Property | Official source | PyTorch port |
|---|---|---|
| Kitchen parameters | `configs/kitchen_config.py` | Expectile 0.7; temperature 0.5; dropout 0.1; discount 0.99; target coefficient 0.005; all initial learning rates 0.0003 |
| Networks | `common.py`, `value_net.py` | Two 256-unit ReLU layers; all linear layers, including outputs, use orthogonal initialization with gain sqrt(2) and zero bias |
| Actor scale | `learner.py`, `policy.py` | State-independent learned log standard deviation per action dimension, initialized to zero and clipped to [-5, 2] |
| Actor density | `policy.py` | Tanh-bounded mean followed by an untransformed diagonal Normal; no inverse tanh or Jacobian in log probability |
| Actor dropout | `common.py`, `policy.py` | Dropout after each hidden ReLU during actor updates; disabled for evaluation |
| Evaluation action | `evaluation.py`, `learner.py` | Deterministic mean, clipped to [-1, 1]; sampled actions are also clipped |
| Dataset actions | `dataset_utils.py` | Clipped to [-1+1e-5, 1-1e-5] for actor, Q, and target Q |
| V objective | `critic.py` | Batch mean expectile squared error against minimum target Q |
| Actor objective | `actor.py` | `-mean(min(exp(temperature * advantage), 100) * log_prob)` |
| Q objective | `critic.py` | Batch mean sum of both TD squared errors; bootstrap uses updated V |
| Update order | `learner.py` | V, actor, Q, then target Q; actor uses updated V and previous target Q |
| Optimizers | `learner.py` | Adam beta1=0.9, beta2=0.999, epsilon=1e-8; no weight decay or gradient clipping |
| Actor schedule | `learner.py` | Cosine decay at update count zero for first update; Q/V rates remain constant |
| Quality and added BC | `actor.py`, `critic.py` | None |

The port clamps the log advantage weight at `log(100)` before exponentiation
to avoid intermediate overflow. This is algebraically equivalent to the
official capped exponential, with possible floating-point rounding differences.

## Scope of correspondence

This implementation has equation and single-update checks. It does not claim
bitwise JAX/PyTorch equivalence, hyperparameter calibration on this custom task,
or original D4RL benchmark reproduction.

- The shared data protocol uses local 81-dimensional observations, persistent
  task-count reward, four specified tasks, and a 280-step evaluation horizon.
  Dataset composition and termination masks differ from the original D4RL
  pipeline. Reported returns are not D4RL normalized scores.
- IQL-Ref uses raw observations, while IQL-M/HQA standardize them. Along with
  actor distribution, loss scaling, and other settings, this prevents a
  single-factor interpretation of their comparison.
- Cosine decay spans the configured 200,000 updates. The pinned official
  training script defaults to 1,000,000, so decay speed differs.
- PyTorch and JAX/Flax/Optax use different initialization realizations and RNG
  streams. Matching initialization distribution and gain does not match the
  matrices generated by the same integer seed. CUDA arithmetic can also differ.
- Model selection and test seed ranges follow this project's
  [experiment protocol](../docs/EXPERIMENTS.md), rather than the official paper's
  original evaluation procedure. The study is not represented as preregistered.

## Tests

From the repository root:

```bash
python -m pytest tests/test_reference_iql.py tests/test_training_resume.py -q
```

The tests verify initialization, global standard deviation, deterministic
evaluation without dropout RNG consumption, and log probability against an
independent NumPy Normal density. A hand-derived linear-network case checks
V, actor, Q, and target updates against every nonzero analytic gradient and
Adam's first-step formula. Further checks cover the advantage cap, independence
from quality fields, cosine schedule, and exact resumed updates with optimizer
moments and dropout RNG restored.

The generic trainer additionally verifies interrupted-versus-uninterrupted
model, optimizer, selected-checkpoint, and metrics-log identity using small
synthetic CPU workloads. These checks do not execute full benchmark training.
